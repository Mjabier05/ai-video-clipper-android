# Video Clipper AI Android

Aplikasi Android starter untuk video clipping berbasis AI.

## Fitur
- Import video dari galeri
- UI editor dengan rekomendasi momen terbaik
- Timeline segment untuk cutting video
- Simulasi AI detect highlight dan caption
- Preview dan export-ready flow

## Stack
- Kotlin
- Jetpack Compose
- Media3 ExoPlayer
- FFmpeg Kit

## Cara menjalankan
1. Buka project di Android Studio.
2. Sinkronkan Gradle.
3. Jalankan aplikasi di emulator atau perangkat Android.

## Catatan
Project ini merupakan starter yang siap dikembangkan lebih lanjut menjadi aplikasi editor video AI yang lebih lengkap.
