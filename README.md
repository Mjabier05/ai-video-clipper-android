# Video Clipper AI Android

Aplikasi Android lengkap untuk trimming dan editing video pendek berbasis AI.

## Fitur utama
- Import video dari galeri
- UI editor dengan rekomendasi momen terbaik
- Timeline segment video
- Simulasi AI highlight dan smart cut
- Preview dan export-ready flow
- Struktur siap dikembangkan ke fitur yang lebih kompleks

## Stack
- Kotlin
- Jetpack Compose
- Material 3
- ExoPlayer (Media3)
- FFmpeg Kit

## Cara menjalankan
1. Buka project di Android Studio.
2. Tunggu Gradle sync selesai.
3. Jalankan aplikasi pada emulator atau perangkat Android.

## Catatan
Project ini sudah dibuat dalam bentuk aplikasi Android yang lebih rapi dan konsisten untuk kemudian dikembangkan menjadi editor video AI yang lebih lengkap.
